Interactive tools for understanding numbers: what they mean, why they are written the way they are, and why the methods we use with them work.

Number Sense (Basic): Whole Numbers

  1. Place Value Exchange Machine Bundle ten counters into one in the next place, or break one back into ten. The ×10 rule, in Indian and International systems.
  2. Chitti's Calculator Make a number using only +1, +10, +100 … buttons. How many ways? Which way takes the fewest clicks?
  3. Number Line Zoom Place a number on the line by zooming in place by place. Each digit picks one step out of ten.
  4. Compare Numbers Zoom in until two numbers part ways. The first digit that differs decides which is bigger, and here is why.
  5. Rounding Neighbours Find the two neighbours, pin the number between them, and see which one is closer. Then the "next digit" shortcut.
  6. Base Exchange Machine The same exchange machine in base 2 to 10. Place value works in any base, not only in tens.
  7. Place Value Zoom Strip Zoom out ×10 again and again, and watch how fast numbers grow, from one to a hundred crore.
